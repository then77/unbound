This reference describes the behavior implemented by Unbound today. It is intended for app developers, protocol integrators, and security reviewers who need exact request and response details.

<Callout title="Alpha status" type="warning">
  APIs and behavior may change during alpha. Unbound exposes OIDC-style discovery and an authorization-code flow, but this documentation does not claim full OAuth 2.0 or OpenID Connect compliance or compatibility with every generic OIDC client.
</Callout>
